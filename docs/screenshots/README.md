# Screenshot D-Library

Folder ini menampung screenshot asli aplikasi D-Library untuk README.

## Cara mengambil screenshot

1. Jalankan aplikasi secara lokal:
   ```bash
   composer setup
   composer dev
   ```
2. Login sebagai pustakawan (`pustakawan@perpustakaan` / `password`)
   atau anggota (`anggota1@perpustakaan.test` / `password`).
3. Ambil screenshot ukuran desktop (1280px+) dan simpan di folder ini.

## Daftar file yang diharapkan

| File | Halaman |
| --- | --- |
| `katalog.png` | Katalog buku (`/buku`) |
| `dashboard.png` | Dashboard pustakawan (`/dashboard`) |
| `dark-mode.png` | Salah satu halaman dengan dark mode aktif |
| `kartu-perpustakaan.png` | Kartu perpustakaan anggota (`/kartu`) |
| `detail-buku.png` | Detail buku (`/buku/{id}`) |
| `peminjaman.png` | Daftar peminjaman (`/peminjaman`) |

> Jangan memakai gambar palsu atau mockup. Kalau screenshot belum ada,
> biarkan tabel di README menampilkan status "segera hadir".
